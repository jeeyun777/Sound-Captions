# 실제 소리 데이터 단계별 평가 (2026-11-13, 실험 기록)

## 실험 구성
- 데이터: ESC-50 (CC BY-NC, 연구·시연용). 사이렌·경적·아기 울음 각 40개, 배경(엔진·비·바람·기차·비행기·헬리콥터), 시험 전용 다른 소리(개·알람시계·종·웃음·까마귀), 출고 학습 전용 기타 소리 16종
- "차" 4대 = 배경 조건 + 차체가 바깥 소리를 막는 정도(저역 통과 1.5\~4kHz). 학습에 쓰지 않은 차로만 평가(leave-one-car-out)
- 폴드: 1\~2 출고 학습, 3 설치 후 이 차에서 만나는 소리(라벨 없는 배경, 반응으로 확인된 사건), 4\~5 시험
- 1초 창, SNR +6/0/−6dB, 문턱 = 학습 차의 배경·다른 소리에서 오경보 1%가 되는 값
- 코드: app/src/test/java/com/soundwitness/app/eval/RealDataLadderTest.kt (앱의 인코더·카운팅 모델·검출기를 그대로 사용)

## 결과 (4대 평균, 창 단위)
| 단계 | 사이렌 | 경적 | 울음 | 배경 오경보 | 다른 소리 오경보 | AUC(배경) | AUC(다른 소리) |
|---|---|---|---|---|---|---|---|
| S0 합성 소리 출고 모델(현재 APK) | 7% | 23% | 21% | 21.5% | 50.0% | 0.753 | 0.496 |
| S1 실제 소리 출고 모델 | 12% | 4% | 4% | 4.2% | 7.7% | 0.792 | 0.547 |
| S1b + 배경 기준선을 빼고 카운팅(+6dB 이상만 1) | 18% | 5% | 13% | 0.7% | 11.7% | 0.835 | 0.593 |
| S1c + 기타 소리 모델 | 10% | 7% | 8% | 0.5% | 7.5% | 0.762 | 0.643 |
| S2 + 이 차 배경 자동 적응 | 10% | 3% | 14% | 5.4% | 6.9% | 0.688 | 0.649 |
| S3 + 반응으로 확인된 사건음 | 16% | 2% | 18% | 7.0% | 10.0% | 0.697 | 0.652 |
| B1 기존 방식(역전파 softmax) | 5% | 9% | 2% | 0.2% | 4.4% | 0.772 | 0.620 |
| B3 기존 방식 + 같은 데이터로 재학습 | 22% | 10% | 10% | 6.7% | 18.0% | 0.744 | 0.570 |

마이크 감도 ±12dB (상위 30% 인코딩, S1 기준): 카운팅은 결과가 그대로. 기존 방식은 +12dB에서 오경보 32%, −12dB에서 재현율 0%.
차 안 학습 비용(4대 합계): 카운팅 정수 더하기 약 67만 회, 역전파 없음 / 기존 방식 곱셈·덧셈 3,230만 회(5 epoch).

## 해석
- 확실한 이점: (1) 합성 → 실제 출고 모델로 오경보 대폭 감소, (2) 배경 기준선 빼기로 배경 오경보 4.2% → 0.7%와 재현율 상승, (3) 마이크 감도 변화에 영향 없음, (4) 학습이 정수 더하기라 차 안에서 바로 반영.
- 아직 보이지 않는 것: 이 차 적응(S2)과 반응 학습(S3)은 재현율을 올리지만 오경보도 함께 올라 AUC가 좋아지지 않음. 절대 재현율(창 단위 10\~20%)이 낮음.
- 원인 후보: 1초 창·28×28 이진 패턴의 표현력, ESC-50 사건음이 짧고 다양함, 적응 중 기준선이 바뀌면서 이전에 학습한 배경 패턴과 어긋남.
- 다음 시도: 사건 단위 평가(3창 중 2창 규칙), 다중 문턱 이진화, 적응 시 배경 모델을 기준선 변경에 맞춰 다시 쌓기, 실제 차 실내 녹음.

## 진단 (2026-11-13 추가, Python 재현 실험 research/)
- "평소와 다른 소리가 있나"(감지): 이 차 배경 대비 대역 초과량만으로 AUC 0.97(+6dB) / 0.94(0dB) / 0.80(−6dB). 감지는 사용자 방법(배경 기준선)으로 충분히 됨.
- "무슨 소리인가"(5종: 사이렌·경적·울음·다른 소리·배경, 0dB 이상): 카운팅 41\~45%, 기존 방식(역전파 softmax) 36%. 입력을 64대역×61프레임으로 키워도 39\~42%로 같음.
- 학습 클립 8→16→24개로 늘리면 평균 35→37→41%(사이렌 50→54→66%). 데이터가 늘면 오르지만 느림.
- 결론: 카운팅이 기존 얕은 방식보다 나쁘지 않음. 한계는 ESC-50의 적은 데이터(종류당 40개)와 얕은 모델 전체에 있음. 소리 종류 판단에는 대규모로 사전학습된 모델이 필요.

## YAMNet 결합 실험 (2026-11-13 밤)
- YAMNet: 구글 공식 yamnet.h5(Apache 2.0)를 numpy로 구현해 실행. 깨끗한 ESC-50에서 사이렌→Siren, 알람→Alarm clock 등 정상 동작 확인. 창 하나당 약 0.1초(파이썬). 앱에는 TFLite(약 4MB)로 넣을 계획.
- 같은 조건(차 4대, 학습하지 않은 차로 평가, SNR +6/0/−6dB, 1초 창), 임계값과 무관한 AUC와 '배경 오경보 5%일 때 재현율'로 비교:

| 단계 | AUC 배경 (0dB 이상) | 오경보 5%일 때 재현율 | AUC 다른 소리 |
|---|---|---|---|
| Y0 YAMNet만 | 0.799 (0.849) | 50% | 0.738 |
| F1 + 배경 기준선 초과량 (사용자 방법) | 0.847 (0.902) | 59% | 0.712 |
| F2 + 이 차 기준선·문턱 자동 적응 | 0.877 (0.929) | 63% | 0.697 |
| F3 + 카운팅 보정 (이 차 배경이 내는 YAMNet 라벨 개수) | 0.891 (0.938) | 66% | 0.685 |
| F4 + 반응 확인 사건음 (종류당 9개) | 0.885 (0.935) | 65% | 0.691 |

- 사건 단위(3창 중 2창): 사이렌 53% → 57%, +6dB에서 72% → 77%.
- 실패한 시도: 감지를 AND 문턱으로 쓰기(재현율 15%로 붕괴), 카운팅이 YAMNet 분류를 대체(15\~20%), YAMNet 라벨로 다른 소리 억제(효과 없음).
- 남은 약점: 개·알람시계 같은 다른 큰 소리와의 구분(AUC 0.69\~0.74).
