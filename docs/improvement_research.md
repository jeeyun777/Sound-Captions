# 소리자막 인식 개선 방안 — 문헌 조사 (2026-11-13)

현재 상태: YAMNet + 배경 기준선 초과량 + 차량별 문턱 + 카운팅 보정. 배경 대비 AUC 0.89, 오경보 5%일 때 재현율 66%. 약점은 다른 큰 소리(개·알람시계·종·웃음)와의 구분(AUC 약 0.7), 낮은 SNR, 적은 데이터.
※ 수치 일부는 초록·2차 출처 기준이며, 인용 전에 원문을 확인해야 합니다.

## 우리 수치의 위치 (비교 기준)
- Castorena 외, Forum Acusticum 2025: 실제 차량 실내 마이크에서 대화·라디오가 있으면 사이렌 재현율 0.08~0.18, 경적 F1 0~0.17. 조용한 실내에서도 사이렌 F1 0.44~0.55. https://dael.euracoustics.org/confs/fa2025/data/articles/000006.pdf
- Cantarini 외, Sensors 2022: 실내 마이크 AUPRC 0.73~0.83, 미세조정 없는 CNN 0.60. https://pmc.ncbi.nlm.nih.gov/articles/PMC9227471/
- Howard 외, Acoustics Australia 2011: 차체는 1kHz 이상을 30dB 넘게 막고, 20m 거리의 사이렌은 라디오가 켜져 있으면 거의 들리지 않음. 사람이 확실히 알아차리려면 배경보다 +15dB 필요(ISO 7731). https://www.acoustics.asn.au/journal/2011/2011_39_2_Howard.pdf
- → +6~−6dB 시험은 과하지 않은 현실적 범위. 우리 사건 단위 57%는 실제 실내 녹음 연구보다 나쁘지 않음. 다만 라디오·대화 간섭은 아직 평가에 없음.

## 1~3번 시험 결과 (2026-11-14, ESC-50 차 4대, 학습하지 않은 차로 평가)
| 방법 | AUC 배경 | 사이렌 vs 다른 소리 AUC | 사건 단위(히스테리시스) 사이렌/경적/울음 | 사건 오경보 배경 / 다른 큰 소리 |
|---|---|---|---|---|
| 이전 최고 F3 (YAMNet+기준선+카운팅) | 0.884 | 0.762 | 77 / 70 / 59% | 18.8 / 63.1% |
| + 1번 임베딩 클래스 통계(이 차 배경 프로토타입, 반응 학습) | 0.931~0.937 | 0.773~0.792 | 74~78 / 69~80 / 78~84% | 22~28 / 78~89% |
| + 3번 사이렌 주파수 궤적 | 0.937 | 0.826 | 83 / 64 / 85% | 17.2 / 85.6% |
| + kNN 미지 소리 거부 | 0.931~0.937 | 0.764~0.797 | 82~84 / 60~61 / 86% | 27~38 / 91~93% (악화) |

- 2번 시간 판정: 히스테리시스·최소 지속시간이 2-of-3보다 사건 재현율을 올림(경적 48→70%, 사이렌 74→77%). 오경보도 함께 오름.
- 다른 큰 소리 오경보를 창 단위 10~20%로 묶으면 재현율은 30~60%로 떨어짐. 이때 1~3번은 배경 오경보를 4.9%에서 0.9%로 줄이고 울음을 36~42%에서 52~60%로 올리지만, 사이렌·경적은 F3과 비슷하거나 낮음.
- 결론: 1~3번은 배경과 울음에는 효과가 있지만 "다른 큰 소리와의 구분"은 해결하지 못함. 남은 핵심 문제.
